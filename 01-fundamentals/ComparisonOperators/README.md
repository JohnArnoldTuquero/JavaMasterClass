# Comparison Operators

Learn how comparison operators work in Java and how they are used to compare two values. Comparison operators always return a boolean value (`true` or `false`), making them essential for decision-making in programming.

---

# Objectives

After completing this lesson, you should be able to:

- Understand how comparison operators work.
- Compare numbers, characters, and other values.
- Interpret boolean (`true` / `false`) results.
- Use comparison operators in conditions and real-life programs.
- Prepare for learning `if`, `else`, and loops.

---

# Concepts to Learn

- Equal To (`==`)
- Not Equal To (`!=`)
- Greater Than (`>`)
- Less Than (`<`)
- Greater Than or Equal To (`>=`)
- Less Than or Equal To (`<=`)
- Boolean Results
- Comparing Variables
- Comparing User Input

---

# Comparison Operators

| Operator | Meaning | Example |
|----------|---------|---------|
| == | Equal To | x == y |
| != | Not Equal To | x != y |
| > | Greater Than | x > y |
| < | Less Than | x < y |
| >= | Greater Than or Equal To | x >= y |
| <= | Less Than or Equal To | x <= y |

# Things to Observe

- Every comparison operator returns either:

```
true
```

or

```
false
```

Notice that comparison operators **do not change** the value of a variable.

They only compare values.

---

Observe the difference between

```
=
```

and

```
==
```

- `=` assigns a value.
- `==` compares two values.

---

Try changing the values and observe how the output changes.
